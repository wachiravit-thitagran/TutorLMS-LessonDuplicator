เพิ่มปุ่มทำสำเนา (Duplicate) ให้บทเรียน แบบทดสอบ งานที่มอบหมาย และหัวข้อ ในหน้า Course Builder ของ Tutor LMS รุ่นฟรี

== Description ==

ปลั๊กอินนี้เพิ่มปุ่ม **ทำสำเนา** ให้กับเนื้อหาในหลักสูตรและหัวข้อ ในหน้า Course Builder ของ Tutor LMS
โดยไม่แก้ไขไฟล์ Core ของ Tutor LMS และไม่ต้องติดตั้ง Tutor LMS Pro

ความสามารถ:

* ทำสำเนาบทเรียน พร้อมเนื้อหา วิดีโอ ไฟล์แนบ featured image และการตั้งค่า preview
* ทำสำเนาแบบทดสอบ พร้อมคำถามและตัวเลือกคำตอบครบทุกข้อ
* ทำสำเนางานที่มอบหมาย พร้อมคะแนน เกณฑ์ผ่าน และไฟล์ประกอบ
* ทำสำเนาหัวข้อพร้อมเนื้อหาทั้งหมดภายใน โดยรักษาลำดับเดิม
* วางสำเนาต่อจากรายการต้นฉบับเสมอ
* เติม "– สำเนา" ต่อท้ายชื่อ และเพิ่มเลขลำดับเมื่อทำสำเนาซ้ำ
* ไม่คัดลอกความก้าวหน้า ผลการทำแบบทดสอบ หรือกิจกรรมของผู้เรียน
* Rollback อัตโนมัติเมื่อการทำสำเนาหัวข้อล้มเหลวกลางทาง
* รองรับทั้งผู้ดูแลระบบและ Instructor ที่มีสิทธิ์แก้ไขคอร์ส

ยังไม่รองรับในรุ่นนี้: Zoom, Google Meet, Interactive Quiz (H5P) และการทำสำเนาข้ามคอร์ส
การตั้งค่า Content Drip ที่มีอยู่จะถูกคัดลอก แต่ยังไม่ได้รับรองแยกกับทุก addon/เวอร์ชัน

= ภาษา =

ข้อความในปลั๊กอินเป็นภาษาอังกฤษ และมีคำแปลภาษาไทยมาให้ในตัว
เว็บไซต์ที่ตั้งค่าภาษาเป็นภาษาไทยจะเห็นข้อความภาษาไทยโดยอัตโนมัติ
รวมถึงคำต่อท้ายชื่อสำเนา ("– Copy" / "– สำเนา")

ผู้ที่ต้องการแปลเป็นภาษาอื่นใช้ไฟล์ languages/tutor-lms-curriculum-duplicator.pot เป็นแม่แบบได้

= เวอร์ชัน Tutor LMS ที่รองรับ =

* Tutor LMS 4.0.x — ตรวจสอบซอร์สโค้ดแล้ว ทำงานปกติ
* Tutor LMS 4.1.0 ขึ้นไป — ยังทำงานได้ แต่ขึ้นคำเตือนให้ทดสอบบน Staging ก่อน
* Tutor LMS 3.0.0 – 3.x — น่าจะใช้ได้ (React Course Builder ตัวเดียวกัน) ยังไม่ได้ตรวจสอบ
* ต่ำกว่า 3.0.0 — ไม่รองรับ ปลั๊กอินจะไม่โหลดปุ่มและ REST endpoint

นอกจากการตรวจเลขเวอร์ชัน ปลั๊กอินยังตรวจก่อนทำสำเนาทุกครั้งว่า post type ที่จำเป็น
ของ Tutor LMS ยังลงทะเบียนอยู่จริง ถ้าโครงสร้างเปลี่ยนจะปฏิเสธคำขอแทนการคัดลอกผิด

== Installation ==

1. อัปโหลดโฟลเดอร์ `tutor-lms-curriculum-duplicator` ไปที่ `/wp-content/plugins/`
2. เปิดใช้งานผ่านเมนู Plugins (ต้องเปิดใช้งาน Tutor LMS 3.0.0 ขึ้นไปก่อน)
3. เข้าหน้า Course Builder แท็บ Curriculum จะพบปุ่มทำสำเนาระหว่างปุ่มแก้ไขและปุ่มลบ

== Frequently Asked Questions ==

= ใช้ร่วมกับ Tutor LMS Pro ได้ไหม =

ได้ แต่ปลั๊กอินจะไม่แสดงปุ่มของตัวเองเมื่อตรวจพบ Pro เพราะ Pro มีปุ่ม Duplicate อยู่แล้ว
หากต้องการให้แสดง ให้ใช้ filter `tlcd_skip_when_pro_active` แล้วคืนค่า false

= เปลี่ยนข้อความ "– สำเนา" ได้ไหม =

ได้ ผ่าน filter `tlcd_copy_suffix`

= สำเนาจะใช้ผู้เขียนคนไหน =

ค่าเริ่มต้นคือผู้ใช้ที่กดปุ่ม Duplicate ปรับเป็นผู้เขียนเดิมได้ผ่าน filter `tlcd_duplicate_author`
